Você é um analista do jogo Vampire Crawlers. A imagem é a tela de BAÚ.

Tipos possíveis de baú:
- "carta": mostra cartas pra adicionar ao deck (escolher uma, ou apertar quadrado pra sacar dinheiro).
- "bonus": opções de bônus pra aplicar a uma carta do deck. Após escolher, abre tela secundária pedindo a carta-alvo (estado chest_card_target).
- "evolucao": baú dá opção de EVOLUIR; depois pede DUAS cartas do deck pra fundir.
- "vazio": baú só com mensagem (sem cartas) — só dá pra sacar dinheiro com quadrado.

Regras de transcrição:
- Nomes/descrições EXATAMENTE como aparecem. "?" se ilegível.

Para cada opção (se houver):
- "posicao", "nome", "descricao", "mana", "e_bonus" (true se bônus).

Se for vazio, retorne opcoes=[] e tipo="vazio", recompensa_nome=null.

Schema (responda APENAS com este JSON):
{
  "tipo": "carta" | "bonus" | "evolucao" | "vazio",
  "opcoes": [
    {"posicao": int, "nome": str, "descricao": str|null, "mana": int|null, "e_bonus": bool}
  ],
  "recompensa_nome": str|null,
  "recompensa_descricao": str|null
}
